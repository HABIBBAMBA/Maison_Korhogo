# Plan : Refactoring du Dashboard Admin

## Problème principal

`resources/views/admin/dashboard.blade.php` est une page HTML standalone (1238 lignes) qui duplique entièrement `layouts/app.blade.php` — navbar, footer, CSS, JS. Résultat : incohérence visuelle avec le reste du site.

## Approche

Réécrire le dashboard pour qu'il étende `layouts.app` comme toutes les autres pages, avec uniquement le contenu spécifique au dashboard dans `@section('content')`.

## Fichier à modifier

- `resources/views/admin/dashboard.blade.php` — réécriture complète

## Changements

### 1. Structure : étendre `layouts.app`
- Supprimer `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`, navbar, footer, CSS dupliqué
- Utiliser `@extends('layouts.app')` + `@section('content')`

### 2. CSS : garder uniquement le spécifique dashboard
- Déplacer dans `@push('styles')` les styles propres au dashboard (stats-grid, stat-card, action-card, activity-list, content-grid)
- Supprimer tous les styles dupliqués (nav, btn, dropdown, alert, table, badge, footer, responsive navbar)
- Les styles de boutons, badges, alertes, tableaux viennent déjà de `layouts.app`

### 3. Stats : supprimer les données fictives
- Supprimer les 4 stats "Rendez-vous", "Vues totales" (toujours à 0, pas de table correspondante)
- Garder uniquement les stats avec données réelles : Biens publiés, Messages reçus
- Pour les admins : Utilisateurs, Actifs, Agences

### 4. Sections vides : supprimer ou rendre utiles
- Supprimer la section "Activité récente" (données `$recentActivities` jamais passées)
- Supprimer la section "Messages récents" (données `$recentMessages` jamais passées)
- Garder le tableau "Biens récents" (données `$recentBiens` — à alimenter depuis le contrôleur)

### 5. Actions rapides : nettoyer
- Supprimer "Panel Admin" (redondant — on est déjà sur le dashboard admin)
- Supprimer les liens `messages.index` et `rendezvous.index` (routes inexistantes)
- Garder : Nouveau bien, Mes biens, Utilisateurs, Agences, Biens (admin)

### 6. Accessibilité
- Ajouter `prefers-reduced-motion` dans `@push('styles')`
- Les `focus-visible` viennent déjà de `layouts.app`

## Contrôleur à modifier

- `app/Http/Controllers/Admin/AdminDashboardController.php`
  - Supprimer les stats fictives (`total_rdv`, `rdv_a_venir`, `total_vues`, `vues_cette_semaine`, `total_transactions`)
  - Ajouter `recentBiens` : les 5 derniers biens formatés pour le tableau
  - Supprimer les variables redondantes (`totalUsers`, `totalBiens`, `totalAgences`, `totalContacts`) — déjà dans `$stats`

## Vérification

1. `php artisan test tests/Feature/AdminRoutesTest.php` — doit passer
2. Vérifier visuellement que le dashboard utilise la même navbar/footer que les autres pages
3. Vérifier que les stats affichent des données réelles
